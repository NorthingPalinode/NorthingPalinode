## 🚀 我的项目

### 🏛️ [古代热搜辟谣局](https://github.com/NorthingPalinode/ancient-hot-search-debunk)

> 古人上热搜，真相由你查。

一款像素风互动历史科普应用。玩家可以刷热搜、逛发现页、和历史人物聊天，遇到可疑的传闻就亲自判断真假，再查看史料和出处。AI 历史人物可以参与讨论，判定依据由服务端预设。

- **技术栈**　Next.js / React / TypeScript
- **荣誉**　🏅 2026 青年 AI 黑客松二等奖

### 📰 [Northing Signal](https://github.com/NorthingPalinode/northing-signal)

> 面向 AI 开发者的个人技术情报系统

从 AI 新闻、研究论文和开源项目中筛选值得跟进的进展，再用分层简报整理出来，方便开发者了解技术动态。
